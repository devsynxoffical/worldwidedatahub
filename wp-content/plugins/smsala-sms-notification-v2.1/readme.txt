== Description ==

Enables the bulk sms service for wordpress and woocommerce. Need API credentials after registering for bulk sms at smsala.com

At a glance, this plugin adds the following:

* Administrators can add api credentials and other options so as to proper functioning of the plugin.
* Bulk SMS gateway will send SMS to customers on different events of order processing.
* Admin can integrate using php code or using wordpress shortcode.
